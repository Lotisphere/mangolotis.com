GrimRoute — real-time loot lookup for Dark and Darker

Hover an item. Know where it drops, how often, and what it sells for.

What it does

Overview

  • Hover an item in game and a card attaches beside the tooltip — no clicking, no alt-tab, no reading your memory or injecting into the game.
  • Route table: where to farm the item, what to kill or which container to open, and the expected number of attempts.
  • Live market quotes, plus a price estimate computed from the rolls on the item you are actually looking at — with a 0–100 roll score.
  • A patch gate detects game updates, compares game / database / cache versions, and syncs the data set for the current build.

How to use

Four steps

  1. Download the archive and unzip it anywhere.
  2. Put your DarkerDB API key — one line, no spaces — into data\api_key.txt. Get a key.
  3. Run grimroute-overlay.exe, and set the game to borderless windowed.
  4. Open the console DATA tab and hit Sync now — also after every game patch.

Ctrl+Shift+H — toggle hover recognition on / off.

Ctrl+Shift+R — open the interactive panel (ROUTES | MARKET); Esc closes it.
