What it does

Features

  • Hover an item in game and a card appears next to the tooltip. It tells you where the item drops, which monster to kill or which container to open, and about how many tries it takes.
  • Market price from DarkerDB, plus an estimate for the rolls on the item you are looking at, with a 0 to 100 roll score.
  • Stash sort. Open your stash in the lobby and press Ctrl+Shift+S to preview the new layout, then press Enter in game and it moves the items for you. Lobby only, it never runs in a raid.
  • Network HUD. A small readout of your ping to the game server. Ctrl+Shift+N shows or hides it.
  • Auto-update. When a new version is out it asks you first, then downloads only the files that changed. Your key and data are left alone.
  • It only reads the screen. It does not read game memory or inject anything into the game.

How to use

Four steps

  1. Install. Mirror download: run grimroute-setup.exe and pick a folder. GitHub: unzip the zip anywhere. Don't use Program Files, the updater needs to write to that folder.
  2. Paste your DarkerDB API key into data\api_key.txt in that folder. One line, no spaces. Get a key here.
  3. Set the game to borderless windowed, then run grimroute-overlay.exe.
  4. In the console, open the DATA tab and click Sync now. The first sync takes 1 to 3 minutes. Sync again after each game patch.

Ctrl+Shift+H hover lookup on or off

Ctrl+Shift+R routes and market panel, Esc closes it

Ctrl+Shift+S stash sort preview, Enter in game to start, Esc to stop

Ctrl+Shift+N network HUD on or off
